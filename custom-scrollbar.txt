Thanh cuộn (scrollbar) trên phần này là **100% Custom CSS** (được thiết kế riêng với hiệu ứng bo tròn, trong suốt và phát sáng nhẹ khi hover), không phải thanh cuộn mặc định thô của hệ thống!

Nó hỗ trợ tương thích hoàn hảo trên tất cả các trình duyệt hiện đại (**Chrome, Edge, Safari, Brave** qua WebKit và **Firefox** qua CSS Scrollbars Standard).

---

### 📋 Toàn bộ mã CSS bạn có thể copy vào dự án khác:

```css
/* ==============================================================================
   1. CHUẨN HIỆN ĐẠI (Hỗ trợ Firefox & Standard CSS)
   ============================================================================== */
@supports (scrollbar-width: thin) {
  * {
    scrollbar-width: thin;
    /* [Màu thanh trượt] [Màu nền rãnh] */
    scrollbar-color: rgba(124, 109, 242, 0.35) transparent;
  }
}

/* ==============================================================================
   2. WEBKIT CUSTOM SCROLLBAR (Chrome, Edge, Safari, Opera, Brave)
   ============================================================================== */
/* Kích thước thanh cuộn (nhỏ gọn 6px) */
::-webkit-scrollbar {
  width: 6px;
  height: 6px;
}

/* Nền đường rãnh trượt (trong suốt để tiệp màu nền) */
::-webkit-scrollbar-track {
  background: transparent;
}

/* Con trỏ kéo (Thumb) ở trạng thái bình thường */
::-webkit-scrollbar-thumb {
  background: rgba(124, 109, 242, 0.28);
  border-radius: 999px;
  border: 1px solid rgba(255, 255, 255, 0.05);
  transition: all 0.2s ease;
}

/* Con trỏ khi rê chuột vào (Hover - sáng hơn + hiệu ứng phát sáng nhẹ) */
::-webkit-scrollbar-thumb:hover {
  background: rgba(124, 109, 242, 0.65);
  box-shadow: 0 0 8px rgba(124, 109, 242, 0.4);
}

/* Con trỏ khi đang nhấn giữ kéo (Active) */
::-webkit-scrollbar-thumb:active {
  background: #8b5cf6;
}

/* Góc giao nhau giữa cuộn ngang và cuộn dọc */
::-webkit-scrollbar-corner {
  background: transparent;
}
```

### 🎨 Mẹo đổi màu sắc theo tông dự án của bạn:
* **Tông màu Tím (hiện tại):** `rgba(124, 109, 242, 0.35)` & `#8b5cf6`
* **Tông màu Xanh Ngọc (Emerald / Teal):** Đổi thành `rgba(32, 191, 169, 0.35)` & `#20bfa9`
* **Tông màu Xanh Dương (Blue / Sky):** Đổi thành `rgba(56, 189, 248, 0.35)` & `#38bdf8`
* **Tông màu Tối / Xám Trung Tính:** Đổi thành `rgba(255, 255, 255, 0.2)` & `rgba(255, 255, 255, 0.4)`
